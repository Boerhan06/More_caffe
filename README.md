## 🌟 Overview

**MORE COFFEE Roasters** is a modern, high-performance, and visually stunning web application designed for a premium specialty coffee roastery and café. Designed with a highly aesthetic bento-grid layout, fluid animations, and premium glassmorphism accents, this application showcases specialty coffee blends, live roasting processes, menu items with roast levels, and multiple café sanctuaries located in **Subang** and **Purwakarta**.

This project represents a professional-grade portfolio website built from scratch with modern frontend engineering principles.

---

## 🛠️ Tech Stack

This project is built using a modern, scalable, and ultra-fast tech stack:

*   **Frontend Library:** [React 19](https://react.dev/) — Utilizing the latest React features for building responsive user interfaces.
*   **Language:** [TypeScript](https://www.typescriptlang.org/) — Fully typed codebase ensuring robust and bug-free development.
*   **Build Tool:** [Vite 6](https://vite.dev/) — Lightning-fast development environment and optimized bundle building.
*   **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) — Next-generation engine for modern utility-first CSS styling.
*   **Animations:** [Framer Motion](https://www.framer.com/motion/) — Fluid, hardware-accelerated spring animations and layout transitions.
*   **Icons:** [Lucide React](https://lucide.dev/) — Sleek, lightweight, and modern vector icon set.

---

## ✨ Key Features

*   🖼️ **Dynamic Bento-Grid Layout:** An aesthetic and responsive layout inspired by modern grid designs.
*   🎨 **Interactive Specialty Menu:** Showcases premium signature menu items, including custom roast-level indicators.
*   ☕ **Specialty Roastery Process:** Interactive showcase of live coffee roasting processes and wholesale bean features.
*   📍 **Sanctuaries & Locations:** Highlights café locations (Subang & Purwakarta) with active open/close statuses and descriptive amenity tags (WiFi, VIP room, outdoor space, photography spots, and parking).
*   📱 **Fully Responsive Design:** Tailored for every screen size with seamless layout adjustments for desktop, tablet, and mobile browsers.
*   💫 **Fluid Spring Animations:** Ultra-responsive hover lifting effects (`whileHover`) and smooth scroll transitions for an interactive, live feeling.

## 🚀 Getting Started

Follow these steps to run the application locally on your computer:

### 📋 Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (version 18.x or later is recommended).

### ⚙️ Installation

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/Boerhan06/More_caffe.git
    cd More_caffe
    ```

2.  **Install Dependencies:**
    ```bash
    npm install
    ```

3.  **Start the Development Server:**
    ```bash
    npm run dev
    ```

4.  **View the Application:**
    Open [http://localhost:3000](http://localhost:3000) in your web browser to enjoy the premium experience!

## 🎨 Design & Animations

Every single UI card and interactive element has been upgraded with a **Premium Spring Physics System** using Framer Motion to provide the user with tactile feedback:
*   **Micro-interactions:** Buttons scale and lift seamlessly on hover (`whileHover={{ scale: 1.05, y: -2 }}`) and press (`whileTap={{ scale: 0.98 }}`).
*   **3D Hover Cards:** Bento cards, Menu items, and Locations lift gently (`y: -8`) and scale beautifully on hover to show interactivity.
*   **Seamless Glassmorphism:** The Navigation bar uses advanced backdrop blur effects to blend perfectly with the body background during scrolling.
